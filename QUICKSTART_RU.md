# Быстрый старт - NewsHub

## 🚀 Запуск приложения за 5 минут

### Шаг 1: Установка зависимостей
```bash
npm install
```

### Шаг 2: Настройка Firebase
1. Создайте проект на [Firebase Console](https://console.firebase.google.com/)
2. Включите **Authentication** → Email/Password
3. Создайте **Firestore Database** (тестовый режим)
4. Скопируйте конфигурацию Firebase

### Шаг 3: Создайте `.env` файл
```env
VITE_FIREBASE_API_KEY=your_api_key_here
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

### Шаг 4: Запуск
```bash
npm run dev
```

Откройте http://localhost:5173

## 🔄 Автоматическое обновление новостей (опционально)

Приложение работает без настройки API, но если хотите автоматическое обновление:

1. Получите API ключ на [NewsData.io](https://newsdata.io) (бесплатно)
2. Откройте **Supabase Dashboard** → Edge Functions → Secrets
3. Добавьте секрет: `NEWSDATA_API_KEY` = ваш ключ
4. Перезапустите приложение

**Новости будут автоматически обновляться каждый час!**

Подробная инструкция: [NEWSDATA_API_SETUP.md](./NEWSDATA_API_SETUP.md)

## 👤 Как стать администратором

**Первый зарегистрированный пользователь автоматически становится админом!**

1. Откройте приложение
2. Нажмите "Регистрация"
3. Заполните форму и создайте аккаунт
4. Вы автоматически получите права администратора
5. Откройте меню → "Админ панель"

## 🆘 Помощь

**Проблемы с Firebase?**
- Проверьте правильность `.env` файла
- Убедитесь, что включены Authentication и Firestore

**Новости не отображаются?**
- Подождите несколько секунд после первого запуска
- Демо-новости создаются автоматически
- Проверьте консоль браузера (F12)

**Не можете войти в админ панель?**
- Убедитесь, что вы первый зарегистрированный пользователь
- Выйдите и войдите снова
