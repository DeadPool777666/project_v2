# Настройка проекта (Firebase + NewsData.io напрямую)

## Изменения в этой версии

Supabase Edge Functions полностью удалены. Теперь фронтенд **напрямую** обращается к NewsData.io API и сохраняет новости в Firebase.

## Быстрый старт

### 1. Установите зависимости
```bash
npm install
```

### 2. Настройте NewsData.io API ключ

Создайте файл `.env` в корне проекта:
```
VITE_NEWSDATA_API_KEY=ваш_ключ_здесь
```

Получить бесплатный ключ: https://newsdata.io (200 запросов/день)

### 3. Firebase уже настроен

Конфигурация Firebase находится в `src/lib/firebase.ts` — она уже содержит ваши данные.

### 4. Запустите проект
```bash
npm run dev
```

## Как работает автообновление

- При загрузке сайта через 5 секунд автоматически запускается первый запрос к NewsData.io
- Затем каждые **10 минут** приходят новые новости
- Каждая новость проверяется на дубликат (по `externalId`) перед сохранением в Firebase
- Категория определяется автоматически по ключевым словам

## Структура запросов к NewsData.io

- 144 запроса/день (каждые 10 минут × 24 часа)
- Лимит бесплатного плана: 200 запросов/день
- Языки: русский и английский
- Топовые источники (`prioritydomain=top`)
