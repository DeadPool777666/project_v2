# NewsHub - Современный новостной портал

## 🌟 Описание

NewsHub - это полнофункциональный новостной сайт с системой авторизации, комментариями, избранными новостями, административной панелью и **автоматическим обновлением новостей** из внешнего API. Приложение построено на React с использованием Firebase Authentication и Firestore для хранения данных, а также Supabase Edge Functions для получения новостей из NewsData.io API.

## 🚀 Быстрый старт

**Хотите запустить за 5 минут?** → [QUICKSTART_RU.md](./QUICKSTART_RU.md)

### Краткая инструкция:

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Настройте Firebase** ([подробно](./FIREBASE_SETUP.md)):
   - Создайте проект в Firebase Console
   - Включите Authentication и Firestore
   - Создайте `.env` файл с конфигурацией

3. **Запустите приложение:**
   ```bash
   npm run dev
   ```

4. **Зарегистрируйтесь первым** - вы стаете администратором!

**Приложение работает сразу с демо-новостями.** Автоматическое обновление новостей опционально ([инструкция](./NEWSDATA_API_SETUP.md)).

## 🔐 Система авторизации

### Firebase Authentication

Приложение использует Firebase Authentication для управления пользователями:

- **Регистрация:** Создание нового аккаунта с email и паролем
- **Вход:** Аутентификация существующих пользователей
- **Первый пользователь:** Автоматически получает роль администратора

### Данные пользователя в Firestore

```javascript
{
  uid: string,           // Уникальный идентификатор
  email: string,         // Email пользователя
  displayName: string,   // Отображаемое имя
  role: "admin" | "user", // Роль
  createdAt: string      // Дата создания
}
```

## 💬 Система комментариев

Комментарии хранятся в Firestore и связаны с:
- Конкретной новостью (newsId)
- Автором комментария (authorId)

**Возможности:**
- Авторизованные пользователи могут оставлять комментарии
- Пользователи могут удалять свои комментарии
- Администраторы могут удалять любые комментарии

## ❤️ Избранные новости

Функционал избранного позволяет пользователям:
- Добавлять новости в избранное одним кликом
- Просматривать все избранные новости на отдельной странице
- Удалять новости из избранного

Данные избранного хранятся в Firestore и связывают userId с newsId.

## 📰 Автоматическое обновление новостей

### Как это работает:

1. **При загрузке приложения** (через 10 секунд):
   - Frontend запускает `fetchNewsFromBackend()`
   - Backend (Supabase Edge Function) получает новости из NewsData.io API
   - Новости сохраняются в Supabase KV Store
   - Новости синхронизируются с Firebase Firestore

2. **Каждые 10 минут** (6 раз в час):
   - Процесс повторяется автоматически
   - Проверяются дубликаты (новости не дублируются)
   - Только новые статьи добавляются в базу
   - **Используется 144 запроса из 200 доступных в день**

3. **Умная категоризация:**
   - Анализ заголовков и описаний
   - 100+ ключевых слов на русском и английском
   - Автом��тическое присвоение категории
   - Цветные бейджи для каждой категории

4. **Админы могут:**
   - Редактировать любые новости (включая полученные из API)
   - Удалять ненужные новости
   - Добавлять собственные новости вручную

### NewsData.io API

- **Бесплатный тариф:** 200 запросов/день
- **Используется:** 144 запроса/день (72% от лимита)
- **Обновление:** Каждые 10 минут = 6 раз в час
- **Категории:** technology, business, sports, science, entertainment, general
- **Языки:** английский, русский
- **Результат:** Постоянно свежие новости!

Подробнее см. [API_OPTIMIZATION.md](./API_OPTIMIZATION.md) и [NEWSDATA_API_SETUP.md](./NEWSDATA_API_SETUP.md)

## 🐛 Решение проблем

### Firebase не инициализируется
- Проверьте правильность конфигурации в `.env`
- Убедитесь, что включены Authentication и Firestore в Firebase Console

### Ошибки при создании комментариев
- Проверьте правила безопасности Firestore
- Убедитесь, что пользователь авторизован

### Не работает избранное
- Проверьте правила безопасности для коллекции `favorites`
- Убедитесь, что пользователь авторизован
